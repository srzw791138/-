# お出かけマップ

家族のお出かけスポットを地図に記録するWebアプリです。
行った場所・行きたい場所をピンで残して、写真と思い出を一緒に保存できます。

## できること

- 📍 地図にスポットを登録（住所検索／地図タップ／現在地）
- ✅「行った」と ⭐「行きたい」を分けて管理
- 📷 スポットごとに写真を何枚でも追加
- ★ 評価・日付・メモの記録
- 🔍 カテゴリ絞り込みと名前検索
- 🚗 詳細からGoogleマップを開いてそのままナビへ

## 使い方

GitHub Pagesで公開すると、スマホからそのまま使えます。

1. このリポジトリの **Settings → Pages** を開く
2. Source で **Deploy from a branch** を選び、Branch は **main / (root)** にして Save
3. 数分後に表示されるURL（`https://srzw791138.github.io/-/ `）を開く

## データの保存について

登録したスポットと写真は、**使っている端末のブラウザの中**に保存されます（サーバーには送信されません）。
別の端末とは同期されないので、メインで使うスマホで登録するのがおすすめです。

## 技術メモ

- `index.html` 1ファイル構成（ビルド不要）
- 地図：Leaflet + OpenStreetMap、住所検索：Nominatim
- 写真は端末内で自動圧縮して IndexedDB に保存
